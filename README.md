# Brandon Funi — Portfolio

Personal portfolio site built with vanilla HTML, CSS, and JavaScript. Features an interactive terminal, AI chatbot, glassmorphism UI, and real-time analytics dashboard.

## Features

- **Interactive Developer Terminal** — Full CLI emulator with commands (`help`, `about`, `skills`, `projects`, `theme`, `chat`, `sudo`)
- **AI Virtual Assistant** — Chatbot trained on Brandon's experience, skills, and projects
- **Animated Stats Counter** — Live-updating project/language/role/framework counters
- **3D Card Tilt** — JavaScript-powered perspective tilt on project cards
- **Ambient Lo-fi Music** — Web Audio API synthesized backing track
- **Command Palette** — `Ctrl+K` quick navigation
- **Multi-language** — English & French support
- **Admin Dashboard** — Hidden insights panel unlocked via `sudo` in the terminal
- **PWA Ready** — Service worker for offline support
- **Dark/Light Theme** — 4 accent colors (emerald, cyan, violet, gold)

## Tech Stack

- HTML5 / CSS3 (Glassmorphism, CSS Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (Canvas particles, Web Audio API, Intersection Observer)
- Bootstrap Icons (SVG inline icons throughout)

## Getting Started

```bash
git clone https://github.com/chrisbranx/my-portfolio.git
cd my-portfolio
# Open index.html in your browser — no build step needed
```

## Deployment

Open `index.html` in any modern browser. The site is fully static and can be deployed to GitHub Pages, Netlify, Vercel, or any static host.
